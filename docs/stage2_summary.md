## 支持的消息格式

### MQTT消息示例

```json
{
    "type": "device",
    "command": "open_gate",
    "shop_id": "shop_001",
    "station_id": "001",
    "data": {},
    "timestamp": 1701234567
}
```

### 语音播报命令

```json
{
    "type": "device",
    "command": "voice_play",
    "shop_id": "shop_001", 
    "station_id": "001",
    "data": {
        "text": "欢迎光临"
    }
}
```

### HomeAssistant控制

```json
{
    "type": "device",
    "command": "ha_control",
    "shop_id": "shop_001",
    "station_id": "001",
    "data": {
        "domain": "switch",
        "service": "turn_on",
        "service_data": {}
    }
}
```
